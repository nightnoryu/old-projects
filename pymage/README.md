# PyMage
A minimal image viewer written in python using tkinter with Pillow (PIL). No killer-features, just bare minimum.

## Supported formats
PyMage supports the same formats as the Pillow module: _BMP, DIB, EPS, GIF, ICNS, ICO, IM, JPEG, JPEG 2000, MSP, PCX, PNG, PPM SGI, SPIDER, TGA TIFF, WebP, XBM_.

For more info check out [Pillow documentation](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html).

## Requirements
It is **strongly** recommended to use the 3rd version of Python.

## Key bindings
- q - quit
- o - open image
- Left/Right - Prev/Next image in the current folder
- f - change mode

The default is forced height of 600 pixels. The second one is image as-is, in it's original size.
