# Random name generator
This program generates [pseudo]random names. This can be used for different purposes, to generate password for example.

## Requirements
- Python 3
- (optional) [pyperclip](https://pypi.org/project/pyperclip/) for copying the generated name to clipboard.

## Shortcuts
- __Esc__ - exit
- __Enter__ - generate a name
- __Ctrl-C__ - copy the name to clipboard
